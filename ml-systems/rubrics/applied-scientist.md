# Applied-scientist rubric

For loops that attach an experiments round to the design round (Section 16.4). The rows are the senior rubric's; **Close the loop** and **Recovery** are weighted double, and the anchors below are the ones the experiments round tests. Material: Chapters 2, 5 and 9.

| Row | Weight | Above the bar, in this loop | Band | Minute |
|---|---|---|---|---|
| **Objective** | 1 | The offline proxy derived from the decision and its costs, at an operating point; the online proxy with its unit of randomisation and its slow read; the gap between them named. | | |
| **Bound** | 1 | The label line complete: provenance, delay, bias, what it cannot see; the randomised slice sized; the judged set sized from the difference to detect. | | |
| **Binds** | 1 | Says whether the label or the measurement binds, and why compute does not. | | |
| **Choose** | 1 | The label design chosen with its price (delay correction, exploration, derived labels); the operating point chosen from costs. | | |
| **Deepen** | 1 | Works the evaluation: the split, the slices, the judge and its calibration, the A/B's size and length, what the average hides. | | |
| **Close the loop** | **2** | The shipping rule written first; the suite by slice with the guardrails on the same page; the feedback row naming the position, selection or intervention loop and its correction; interleaving as the filter before the A/B; the staleness curve setting the cadence. | | |
| **Recovery** | **2** | Sizes a judged set from a difference on the spot; names the judge's failure modes unprompted; concedes a metric that was chosen without an operating point and replaces it. | | |

**Questions the experiments round asks, and the chapter that answers each:** how would you size the A/B (9); what is a randomised slice for (5, 11); what does a model judge get wrong (9); why does a random split leak (5); what does the average hide (9); when does a lift on the proxy hurt the objective (2).
