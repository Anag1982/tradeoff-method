# Rubrics and self-marking sheets

Scoring sheets for *The Tradeoff Method for ML Systems*. Each scores the five moves of the method, with the choose move split into its decision and its deepening and a seventh row for recovery, in three bands with anchor behaviours (Chapter 16). None of them scores the diagram.

| Sheet | Use for |
|---|---|
| [senior.md](senior.md) | Senior loops; the general sheet, and the one Chapter 15's mock protocol uses |
| [staff.md](staff.md) | Staff loops and prompts that arrive as somebody's proposed solution (Chapter 14) |
| [applied-scientist.md](applied-scientist.md) | Loops with an experiments round; Close the loop and Recovery weighted double |
| [platform.md](platform.md) | Platform and infrastructure loops; Bound and Deepen weighted toward serving |
| [red-flags.md](red-flags.md) | The sixteen red flags of Section 16.5, with the chapter that answers each |
| [self-marking/](self-marking/) | One sheet per worked design (fourteen) and per unworked brief (twelve), with the anchor for every row filled in for that brief |

Scoring: mark each row below, at or above the bar, and write the minute at which the row's artefact appeared. A candidate at the bar on every row is a hire; below on two rows is usually not; two red flags end the discussion. Mark the row that decides the brief first (each self-marking sheet names it): if that row is below the bar, the design is below the bar whatever the rest says.

These rubrics are a composite of published loop guidance and the author's experience. They are not any company's document.
