# Staff rubric

The rows are the senior rubric's; "at the bar" for staff is the senior sheet's "above the bar." This sheet gives the staff "above the bar" anchor for each row (Chapters 14 and 16). Score at or above, and note the minute.

| Row | Above the staff bar | At / above | Minute |
|---|---|---|---|
| **Objective** | Turns the request into the problem it is solving, with a number and a date, and names the quality that will pay for it, per product, with an owner who signs. Says which of the possible problems is worth solving and which is not. | | |
| **Bound** | Bounds the portfolio rather than the system: models, fleets, judged sets, teams. Finds the cheap and reversible move and says its size before drawing anything expensive. | | |
| **Binds** | Names the constraint that is not a number: the ability to measure a quality price, the ownership of a definition, the calendar of a comparison. Says which objective the time allows and which it does not. | | |
| **Choose** | Commits to the cheapest design that meets the brief and names the rejected alternatives with the number that rejected each. The design is a sequence ordered by reversibility, with the irreversible step last and the evidence in front of it. | | |
| **Deepen** | Goes deep on the hard part nobody has named, usually a quality price hidden in a fourth decimal or a hard slice, and builds the instrument that would show it before it is needed. | | |
| **Close the loop** | The loop is on the change, not only the system: what is measured during the migration, what reverts each stage, what the canary is. Harm includes the shared fate a consolidation creates. | | |
| **Recovery** | Refuses aloud with a number: the product that cannot pay, the quarter that cannot be compressed, the model the machine must not be allowed to call. Offers what can be given instead. | | |

**The three verbs, with their ML edge:** decide (the objective is a design decision; the staff candidate makes it rather than reads it), cut (the smaller model, the shorter context, the rule ahead of the model, the feature that does not go on the stream, each with a measured price), refuse (the fraud model that stays off the cost list; the fine-tune the memory product cannot have; each with its number).

**Readiness signal:** the objective behind the request stated by minute five; the cheap reversible move named before anything expensive; the irreversible step named and placed last; at least one refusal with a number.
