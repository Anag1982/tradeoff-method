# Self-marking sheets

One sheet per worked design of Part III (`designs/`, fourteen) and per unworked brief of Appendix B (`briefs/`, twelve). Each sheet names the row of the rubric the brief is decided on, gives the above-the-bar anchor for every row *for that brief*, lists the numbers a marker should expect to hear, and the red flags particular to it.

Use: work the design or brief against the clock from the brief alone (Chapter 15's protocol), then mark the deciding row first. If it is below the bar the design is below the bar whatever the rest says, which is how loops read it too. Then mark the other rows. The general anchors are in `../senior.md`; these sheets are the specific ones.
