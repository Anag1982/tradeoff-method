# B.9 Dynamic pricing for ride-hailing

*Unworked brief · decided on **Close the loop** · Appendix B*

Set the price of a ride by place and time.

Mark the deciding row first. Then score every row below, at or above the bar against the anchor given, and write the minute the artefact appeared.

| Row | Above the bar on this brief | Band | Minute |
|---|---|---|---|
| **Objective** | Completed rides and driver hours, not revenue per ride; wait time as the guardrail. | | |
| **Bound** | 1M rides/day; a quote before commitment; drivers move with a ten-minute lag; the label depends on the quote; a regulatory cap. | | |
| **Binds** | The feedback loop, three times over: quote → label, drivers learn the model, the cap changes behaviour. | | |
| **Choose** | A forecast of supply and demand and a rule that sets the price; the randomised slice to learn the demand curve. | | |
| **Deepen** | The stadium: what the price does in fifteen minutes and what the model learned last time. | | |

| **Recovery** | Defends keeping the pricing rule rather than learning it. | | |

**Numbers the marker should expect to hear:** 1M/day; ten-minute lag; 3× cap.

**Red flags particular to this brief:** learning the price end to end; no randomised slice.
