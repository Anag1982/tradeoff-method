# Twelve unworked briefs

These are the briefs of Appendix B of *The Tradeoff Method for ML Systems*, in a form a study group can use. Each file has two halves. The **candidate's half** is the prompt alone. The **interviewer's half** holds the numbers the interviewer gives only if asked, three pushes to deliver in the questions block, a twist for minute thirty, and rubric notes that name the row of Chapter 16's rubric the brief is decided on and what an above-the-bar answer does there, without giving the design away.

Working alone: read the prompt, run the forty-five minutes by the protocol of Chapter 15 with the sheets in `../templates/`, then read the rest and score yourself on the sheets in `../rubrics/`. In pairs: the candidate sees the prompt; the interviewer sees everything, records the minute of each artefact and of the first model name, and swaps roles next time.

No solutions exist for these briefs anywhere in the book, and none will be added here.
