# Twelve unworked briefs

These are the briefs of Appendix B of *The Tradeoff Method*, in a form a study group can use. Each file has two halves. The **candidate's half** is the prompt alone. The **interviewer's half** holds the numbers the interviewer gives only if asked, three pushes to deliver in the questions block, a twist for minute thirty, and rubric notes that name the axis the brief turns on and what an above-the-bar answer does at each move, without giving the design away.

Working alone: read the prompt, run the forty-five minutes by the protocol of Chapter 15, then read the rest and score yourself. In pairs: the candidate sees the prompt; the interviewer sees everything, scores in real time, and swaps roles next time.

No solutions exist for these briefs anywhere in the book, and none will be added here.
