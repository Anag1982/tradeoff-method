# Mock-interview rubrics

Four scoring sheets, one per kind of loop. Each scores the five moves of *The Tradeoff Method* plus depth, never the finished diagram, in three bands with anchor behaviours. Use them alone against a recording, or in pairs with the interviewer scoring in real time (Chapter 15).

| Sheet | Use for |
|---|---|
| [senior.md](senior.md) | Senior loops and the six classic briefs |
| [staff.md](staff.md) | Staff loops and situation-shaped prompts (Chapter 14) |
| [ai-adjacent.md](ai-adjacent.md) | Retrieval, vector search, recommendation and other briefs whose failures are silent |
| [migration.md](migration.md) | Migrations, splits and any change to a system that is already running |

Scoring: mark each row below, at, or above the bar, and write the minute at which the row's artefact appeared on the board. The minute is the number to track across mocks; the band follows once the minutes are stable.

These rubrics are a composite of published loop guidance and the author's experience. They are not any company's document. Read the one for the company you are interviewing with if it publishes one.
