# The Tradeoff Method

Companion material for two books by Avishek Nag. Each book has its own directory; open the one that matches the book in your hands.

| Book | Directory | What is inside |
|---|---|---|
| *The Tradeoff Method: System design interviews as decisions you can defend* (2026) | [`system-design/`](system-design/) | The four artefact sheets, twelve unworked briefs, four rubrics, the capacity toolkit, 22 figures, errata |
| *The Tradeoff Method for ML Systems: Machine learning and GenAI system design interviews* (2026) | [`ml-systems/`](ml-systems/) | The five artefact sheets and the mock-protocol sheets, twelve unworked briefs, rubrics, the ML cost-and-capacity toolkit, 24 figures, errata |

Both books teach the same five-move method — frame a brief, budget it, find the constraint that binds, commit, and stress the result — and Volume 2 retunes it for systems with a learned component. The material in each directory is self-contained; nothing in one depends on the other.

Corrections: open an issue, or a pull request against the `ERRATA.md` in the relevant directory, giving the printing (on the copyright page) and the page.
